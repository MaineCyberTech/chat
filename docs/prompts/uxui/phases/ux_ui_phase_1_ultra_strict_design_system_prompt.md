# ux/ui phase 1 — ultra-strict design system foundations prompt

this is the more forceful version of phase 1.

## non-negotiable outcomes

explicitly harden or create:

- token architecture
- semantic color system
- dark-first readability model
- typography system
- density model
- motion model
- primitive component matrix
- coherent state styles
- theme architecture
- documentation + validation

## forceful rules

- do not leave token architecture implicit
- do not leave semantic colors undefined
- do not leave typography as ad hoc class usage
- do not leave focus styling weak or inconsistent
- do not rely on one-off component fixes when token/primitives fixes are better
- do not create a second competing style system
- do not scatter random raw color values if semantic tokens should be used

## required validation

run the most relevant commands available:

- web lint / typecheck / test / build
- ui lint / typecheck / test
- root lint / typecheck / test / build where practical

## report format

- ux/ui phase 1 (ultra-strict): design system foundations
- objective
- repo inspection summary
- ux/ui findings by priority
- implementation plan
- files created
- files modified
- design system changes
- commands run
- validation results
- blockers
- next recommended step
