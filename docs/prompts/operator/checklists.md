# checklists

## bootstrap checklist

- [ ] root monorepo config exists
- [ ] root scripts exist and are coherent
- [ ] lint/format/test/typecheck/build configs exist
- [ ] web and api scaffolds exist
- [ ] shared ui and db packages exist
- [ ] infra folders exist
- [ ] docs folders exist
- [ ] validation ran
- [ ] blockers are explicit

## final reconciliation checklist

- [ ] monorepo/workspace config audited
- [ ] build/import/type issues audited
- [ ] env and domain usage audited
- [ ] docker/traefik audited
- [ ] terraform/cloud-init audited
- [ ] workflows audited
- [ ] docs/runbooks audited
- [ ] dead files/duplicate systems addressed

## frontend release gate checklist

- [ ] p0/p1/p2/p3 findings were produced
- [ ] release-readiness grading was produced
- [ ] accessibility readiness was graded
- [ ] visual consistency was audited
- [ ] responsive readiness was audited
- [ ] actionable issues were repaired
- [ ] residual risks are clearly documented
