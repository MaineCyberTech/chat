# Final Reconciliation Prompt Pack

This pack is for the **strict end-of-process reconciliation step** after earlier audit and implementation planning phases have already been run.

## Purpose

Use this pack to force an intelligent AI to:

- compare all prior audit outputs against each other
- detect contradictions, omissions, and drift
- reconcile inconsistencies across architecture, UI/UX, infra, testing, docs, and rollout recommendations
- produce one authoritative, production-safe final report

## Recommended use cases

- after Phases 1–7 of the comparative repo audit
- after a frontend-specific UX audit
- before implementation begins
- after implementation plans exist and need consistency validation

## Included prompts

- strict reconciliation operator instructions
- audit artifact validation prompt
- contradiction detection prompt
- risk and guardrail normalization prompt
- final single-source-of-truth synthesis prompt
