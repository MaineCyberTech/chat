# Reconciliation Checklist

Use this checklist before running the final reconciliation pass.

- [ ] Compare audit output is present
- [ ] UI/UX audit output is present
- [ ] Reconciliation Input Index is filled out
- [ ] Do-Not-Break Guardrails are documented
- [ ] Keep/Adapt/Skip Matrix is documented
- [ ] Known Good Baseline is documented
- [ ] Open Questions / Possible Conflicts are documented
- [ ] Visual Baseline Index is documented or intentionally skipped
- [ ] Priority Order is documented
- [ ] Final reconciliation prompt pack is available
- [ ] Output location for final reconciled report is decided
- [ ] Human owner knows which files/folders are off-limits

## Ready State

When all critical sections above are filled in, the reconciliation pass should have enough structured input to produce a higher-quality final report.
