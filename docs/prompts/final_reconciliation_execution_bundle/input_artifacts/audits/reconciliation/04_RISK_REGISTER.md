# Risk Register

| ID    | Area      | Risk                                                   | Why it matters                   | Likelihood | Impact   | Blast radius       | Mitigation                                                                   | Rollback                               |
| ----- | --------- | ------------------------------------------------------ | -------------------------------- | ---------- | -------- | ------------------ | ---------------------------------------------------------------------------- | -------------------------------------- |
| R-001 | Auth      | Auth middleware or context change breaks login         | Entire app inaccessible          | Low        | Critical | All users          | Don't touch auth module without comprehensive tests                          | Revert auth changes                    |
| R-002 | Caddy     | TLS cert re-issuance triggers Let's Encrypt rate limit | HTTPS outage until Jun 21        | High       | High     | All traffic        | Don't modify Caddy TLS config until Jun 21; use self-signed/Cloudflare certs | Restore previous Caddyfile             |
| R-003 | DB        | Migration modifies existing schema                     | Data loss / runtime errors       | Low        | Critical | All data, API, Web | Always additive migrations only                                              | Revert migration + restore from backup |
| R-004 | Socket.io | Event contract change (rename/remove)                  | Real-time messaging breaks       | Low        | High     | Chat feature       | Additive events only; test all existing events                               | Revert event changes                   |
| R-005 | Deploy    | SSH pipeline change breaks deployment                  | Cannot update production         | Medium     | High     | Production         | Test deploy workflow in staging first                                        | Revert workflow file                   |
| R-006 | Droplet   | Adding worker + Redis causes OOM on 512MB droplet      | Site down                        | Medium     | High     | Entire app         | Upgrade droplet before adding services                                       | Remove worker/Redis containers         |
| R-007 | UI Dialog | Focus trap breaks existing dialog behavior             | Modals unusable with keyboard    | Low        | Medium   | Create dialogs     | Unit test + keyboard E2E test                                                | Revert dialog.tsx                      |
| R-008 | Icons     | lucide-react replacement misses buttons                | Some Unicode icons persist       | Low        | Low      | Visual             | Grep for Unicode chars post-change                                           | Revert package + imports               |
| R-009 | Build     | Next.js standalone EPERM on Windows                    | Build fails locally              | High       | Medium   | Local dev only     | Use WSL or Linux for builds; CI unaffected                                   | N/A — platform limitation              |
| R-010 | Terraform | Import-based workflow creates duplicate droplets       | Multiple droplets, DNS confusion | Medium     | Medium   | Dev infra          | Cleanup step in workflow deletes old droplets                                | Manual DO console cleanup              |
