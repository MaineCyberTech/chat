# Phase 2 — Contradiction Detection and Resolution

## tasks

- compare overlapping findings across all artifacts
- identify direct contradictions, priority conflicts, and remediation conflicts
- resolve each contradiction explicitly using repo evidence when available
- if not resolvable, mark as manual verification required

## output

For every contradiction include:

- conflicting artifacts
- the exact point of conflict
- chosen resolution or unresolved status
- why that resolution was chosen
