# Frontend Deep-Dive Audit Prompt (Standalone Pack)

## Purpose

Perform a frontend-only deep audit with a strong UX/UI and interaction focus.

---

## Frontend-Specific Categories

F1 — Design System Integrity
F2 — Layout & Navigation
F3 — Chat UX
F4 — State Management & Data Flow
F5 — Accessibility
F6 — Responsive Design
F7 — Performance
F8 — Interaction Quality
F9 — Visual Consistency
F10 — Component Architecture

---

## Required Outputs

- Severity classification
- Findings table
- Category checklists
- UX improvements
- Frontend GO / NO-GO decision

---

## Severity Model

Same P0–P3 model applies

---

## Output Format

- FRONTEND AUDIT REPORT
- Findings
- Fixes
- Visual issues
- Decision

---

## Decision Rules

GO: No P0 UX or accessibility issues
NO-GO: broken layout, unreadable UI, or accessibility failure
