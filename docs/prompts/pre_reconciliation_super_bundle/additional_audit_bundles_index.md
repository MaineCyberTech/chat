# Additional Audit Bundle Index

These folders are intended to be run before `final_reconciliation` if you want richer comparison inputs.

## Included folders

- **security_authz_tenancy_audit_pack** — Authentication, authorization, RBAC, tenancy, secrets, session security, and exploit-path audit.
- **infra_deployment_resilience_audit_pack** — Terraform/IaC, DNS, networking, CI/CD, deploy safety, rollback, resilience, and observability audit.
- **database_schema_data_lifecycle_audit_pack** — Schema, migrations, constraints, indexing, tenant data shape, retention, and data lifecycle audit.
- **api_worker_integrations_audit_pack** — API contracts, background workers, retries, idempotency, async correctness, and integration boundary audit.
- **testing_qa_cicd_audit_pack** — Test strategy, coverage, CI enforcement, quality gates, fixtures, and regression prevention audit.
- **docs_devex_operations_audit_pack** — Onboarding, docs, scripts, runbooks, repo ergonomics, and operator readiness audit.
