# Feature Test Expansion Prompt

You are a principal QA automation engineer.

## Objective

Generate a concrete test strategy for the new feature set, including unit, integration, E2E, performance, and reliability coverage.

## Cover

- threads
- mentions and notifications
- RBAC overrides
- webhooks
- search
- virtualization
- optimistic UI
- editor interactions
- themes
- responsive layouts
- media UI where applicable

## Output

1. test matrix by feature
2. recommended tool(s)
3. CI execution tiers
4. flaky test prevention guidance
5. seed data / fixture requirements

## Write to

`/docs/audits/latest/feature_test_expansion_plan.md`
