# Platform Readiness for Feature Expansion Prompt

You are a principal platform engineer validating that the repository can absorb the planned feature set without collapsing under architectural drift.

## Evaluate

- shared types/contracts
- monorepo package boundaries
- DB migration discipline
- API versioning / contract evolution
- realtime event naming / payload stability
- observability and analytics readiness
- search/index maintenance needs
- background job or worker needs for future roadmap items

## Output

1. platform readiness score
2. required enabling work before feature expansion
3. package/repo restructuring recommendations
4. future worker / notification / indexing suggestions

`/docs/audits/latest/platform_readiness_for_features.md`
