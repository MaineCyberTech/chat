# Media Rich-Text Editor Prompt

You are a principal frontend/editor engineer building a **media-rich input experience**.

## Product requirement

The message input must support:

- markdown shortcuts
- drag-and-drop file uploads
- image paste handling
- emoji picker popover
- autocomplete popovers for `@mentions` and `#channels`

## Required scope

- choose editor architecture (enhanced textarea vs rich editor)
- mention and channel suggestion UX
- attachment draft state model
- upload progress and error handling
- sanitization / content safety rules
- keyboard navigation and accessibility
- mobile-safe compose behavior

## Required outputs

1. editor architecture decision
2. component breakdown
3. mention/autocomplete state model
4. attachment pipeline plan
5. accessibility and keyboard plan
6. tests for paste, drag-drop, emoji, and mention flows
