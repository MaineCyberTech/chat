# Liquid Responsive Design Prompt

You are a principal frontend UX architect designing a **liquid, responsive, three-column collaboration layout**.

## Product requirement

Desktop layout should support:

- server/workspace list
- navigation / channels drawer
- main chat frame

Mobile layout should support:

- slide-out sheets / drawers
- floating action controls where appropriate
- bottom navigation tab paradigm when helpful
- media and thread-safe navigation behavior

## Required scope

- current layout audit
- breakpoint strategy
- mobile navigation model
- sidebar collapse and restore rules
- thread and media panel behavior on smaller screens
- performance and accessibility considerations

## Required outputs

1. layout architecture plan
2. responsive breakpoint matrix
3. component and routing impact map
4. mobile interaction plan
5. risks to existing navigation and mitigation steps
