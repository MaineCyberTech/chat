# Quick Start — Portal Frontend UI/UX Audit

1. Prepend `00_GLOBAL_OPERATOR_INSTRUCTIONS.md` to each phase.
2. Run phases one at a time.
3. Keep all working frontend behavior intact unless explicitly justified.
4. Require evidence-driven observations and clear UX risk assessment.
5. Use `08_UI_UX_PHASE_8_FINAL_FRONTEND_RECONCILIATION.md` as the final master frontend audit artifact.
