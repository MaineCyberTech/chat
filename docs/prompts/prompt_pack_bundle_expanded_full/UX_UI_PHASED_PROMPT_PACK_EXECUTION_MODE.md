# UX/UI Phased Prompt Pack — Execution Mode

## Principal-Level Frontend / Design System / Product Experience Implementation Pack

Use this to drive UX/UI work one layer at a time.

## Phase Order

1. Design System Foundations
2. App Shell, Navigation, and Information Architecture
3. Channel, Chat, Thread, and Composer Experience
4. Search, Profile, Content, Settings, and Utility Surfaces
5. Responsiveness, Accessibility, and Interaction Polish
6. Customization, Preferences, and Theme Persistence
7. UX/UI Validation, Documentation, and Final Frontend Reconciliation

## Global Priorities

- P0: readability, shell integrity, accessibility, provider/theme wiring, responsive integrity
- P1: navigation clarity, chat ergonomics, profile/search/settings-quality, mobile quality
- P2: spacing, motion, iconography, normalization, polish
- P3: future enhancement only
