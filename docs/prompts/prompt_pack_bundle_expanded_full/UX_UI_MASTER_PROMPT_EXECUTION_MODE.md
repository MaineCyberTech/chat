# UX/UI Master Prompt — Execution Mode

## Principal-Level Frontend / Design System / Product UX Overhaul

Use this for a broad frontend design-system and UX pass.

## Design Direction

The target UX/UI should synthesize the strongest product qualities of:

- Discord for communication ergonomics and chat density
- Teams for enterprise collaboration structure
- LinkedIn for professional polish and hierarchy
- SharePoint for structured information architecture

Do not clone proprietary layouts or branding.
Create an original, cohesive, premium-dark, readable, customizable product UI.

## Primary Goals

- dark-first readability
- professional + collaborative feel
- disciplined customization
- keyboard productivity
- responsive behavior
- accessibility
- design system rigor
- calm but high-density enterprise UX

## Required Areas To Improve

- global app shell
- navigation
- chat/channel/thread/composer surfaces
- search and command surfaces
- profile/member surfaces
- document/content views
- notification/activity surfaces
- settings/preferences/admin surfaces
- theme/customization architecture
