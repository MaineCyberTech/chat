# Chat UX Specialization Prompt Pack — Execution Mode

## Principal-Level Communication Experience Implementation Pack

This specialized pack focuses on the **core communication experience**.

## Scope

- channel view
- message list
- thread view
- composer
- unread markers
- reactions
- presence/typing/connectivity cues
- communication side panels/context panels
- mobile chat ergonomics

## Internal Stages

### Phase A — Message Stream Foundations

Improve message grouping rhythm, avatar/name/timestamp hierarchy, density, system-message distinction, attachment presentation, and message state clarity.

### Phase B — Thread UX and Context Retention

Improve thread discoverability, parent-message context preview, thread metadata, side-panel vs full-page presentation, and mobile thread usability.

### Phase C — Composer, Mentions, Attachments, and Action Surfaces

Improve composer prominence, toolbar discipline, mentions UX, emoji/attachment entry, draft confidence, edit/reply states, and keyboard ergonomics.

### Phase D — Presence, Reactions, and Conversation State Cues

Improve presence, typing, connection banners, reaction pills, unread markers, mention markers, scroll-to-latest clarity, and optimistic-state cues.

### Phase E — Mobile and High-Density Chat Ergonomics

Improve mobile chat readability, mobile composer ergonomics, thread navigation, side-panel fallback behavior, compact mode readability, and cross-breakpoint consistency.

## Priority Model

- P0: unreadable message stream, broken message/thread/composer layout, broken mobile communication flow
- P1: weak thread discoverability, weak composer UX, weak reaction/presence clarity, poor density management
- P2: menu/action polish, spacing rhythm, motion refinement, microcopy, iconography
- P3: future enhancement only
