# Quickstart

## Drop-in path

Copy the contained `docs/prompts/progressier_pwa_execution_bundle/` folder into the repository root.

## Recommended usage

Provide the AI coding agent with these files in order:

1. `01_global_operator_instructions.md`
2. `02_master_prompt_progressier_pwa_execution.md`
3. `03_phase_1_repo_inventory_and_guardrails.md`
4. Continue phase-by-phase
5. Finish with `09_final_reconciliation_and_output_contract.md`

## Best use case

Use this bundle when the agent:

- has full repository access
- can inspect, edit, run commands, and validate
- should behave conservatively and preserve existing working behavior
