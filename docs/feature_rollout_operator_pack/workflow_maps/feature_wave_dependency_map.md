# Feature Wave Dependency Map

## Wave dependency logic

- Wave 1 must complete before Wave 2 because search, notifications, and hidden visibility semantics depend on correct data and permission models.
- Wave 2 should complete before some Wave 3 UX surfaces so search/webhook affordances are real rather than speculative.
- Wave 3 should stabilize before broad media UX work if layout/state architecture is changing heavily.
- Wave 5 should never be skipped.
